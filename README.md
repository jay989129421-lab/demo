# Python Assignments

A collection of 7 Python assignments covering collections, functions, NumPy, regex, pandas and data visualization.

| # | File | Topic |
|---|------|-------|
| 1 | `assignment1_student_data.py` | Student records using Dictionary, Tuple & List (add / delete / update) |
| 2 | `assignment2_largest_of_three.py` | Largest of three numbers |
| 3 | `assignment3_right_triangle.py` | Right-angled triangle check using a function |
| 4 | `assignment4_matrix_addition.py` | Matrix addition (NumPy and loops) |
| 5 | `assignment5_pan_validation.py` | PAN number validation using regex |
| 6 | `assignment6_data_preprocessing.py` | Data preprocessing with pandas (`students_raw.csv`) |
| 7 | `assignment7_data_visualization.py` | Line, bar, scatter plots & heatmap (`sales_data.csv`) |

## Setup
```bash
pip install -r requirements.txt
python assignment1_student_data.py
```
